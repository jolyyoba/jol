# Звонок домой

Android-приложение для быстрого вызова на одну Яндекс Станцию. Интерфейс на Jetpack Compose Material 3 Expressive поддерживает системные цвета Android 12+, светлую и тёмную темы.

## Настройка

1. Установите приложение на Android 8.0 или новее.
2. На телефоне откройте приложение Яндекса и войдите в аккаунт с доступом к умному дому. Проверьте, что вызов на колонку разрешён.
3. В приложении «Дом с Алисой» выберите Станцию, откройте «Помощь» → «Об устройстве» и скопируйте идентификатор.
4. В «Звонке домой» нажмите «Настроить звонок», вставьте идентификатор и сохраните. Нажмите «Позвонить» или добавьте ярлык на рабочий стол, если он поддерживается.

Идентификатор хранится в настройках приложения на телефоне. Вызов передаётся установленному приложению Яндекса по неофициальной ссылке. Её совместимость с конкретной версией Яндекса и Станцией проверяется на телефоне. Если ссылка не срабатывает, у Яндекса есть [штатный виджет звонков](https://alice.yandex.ru/support/ru/smart-home/widgets).

## Сборка

Откройте проект в Android Studio с поддержкой AGP 9.1.1 или запустите `./gradlew :app:assembleDebug` с JDK 17+ и установленным Android SDK 37.0. APK будет в `app/build/outputs/apk/debug/app-debug.apk`. Для статической проверки запустите `./gradlew :app:lintDebug`.
