# Звонок домой

Android-приложение для быстрого доступа к звонкам на Яндекс Станцию. Интерфейс на Jetpack Compose Material 3 Expressive поддерживает системные цвета Android 12+, светлую и тёмную темы.

## Настройка

1. Установите приложение на Android 8.0 или новее.
2. В «Доме с Алисой» войдите в аккаунт умного дома и проверьте, что на Станцию можно звонить.
3. Нажмите «Открыть „Дом с Алисой“» в «Звонке домой», затем нажмите трубку рядом со Станцией. Чтобы видеть карточку колонки сразу, добавьте её в [«Избранное»](https://alice.yandex.ru/support/ru/smart-home/favourites).

Если на телефоне есть версия приложения поиска Яндекса, которая обрабатывает старую ссылку вызова, «Звонок домой» предложит настроить прямой вызов. Скопируйте идентификатор из «Дом с Алисой» → Станция → «Помощь» → «Об устройстве». Идентификатор хранится локально. Работа старой ссылки зависит от версии Яндекса. Для быстрого доступа с рабочего стола проверьте [виджеты «Умного дома»](https://alice.yandex.ru/support/ru/smart-home/widgets).

## Сборка

Откройте проект в Android Studio с поддержкой AGP 9.1.1 или запустите `./gradlew :app:assembleDebug` с JDK 17+ и установленным Android SDK 37.0. APK будет в `app/build/outputs/apk/debug/app-debug.apk`. Для статической проверки запустите `./gradlew :app:lintDebug`.
